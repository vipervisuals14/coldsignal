A QUICK START

From source to signal.

  1. Choose your visual.

    Add an image or video. Native 4K sources stay full resolution. The procedural field is available if you want to start without an image.

  2. Add the song on your computer.

    Choose a song locally to analyze its energy. A CSV can also supply motion data, but contains no sound; choose the matching audio file for a soundtrack. Source-video audio is muted; the separate song is the soundtrack.

  3. Frame it. Make it move.

    Drag the canvas to orbit, use the mouse wheel for framing, and adjust the Raster, Camera and Finish controls. Space plays or pauses outside an input field.

  4. Render the section you need.

    Song start is an offset in the music file. The video visual begins at its own start and loops if enabled. A positive sync nudge delays the reaction only, not the audio.

Keyframes: create your own animation

Click ◇ beside a numeric control to add its first key. Move the playhead, then change that slider: an already-animated control automatically gets a key at the new time. The keyframe editor below the waveform lets you select a control, drag its diamonds in time, edit values, delete keys and undo changes.

Each key’s To next key setting selects Linear, Ease in/out, or Hold for the outgoing segment. The first/last value is held outside the keys. New and moved keys snap to the current frame rate; times are stored as seconds relative to the selected section. Changing Song start does not shift the keys. Shortening Duration retains later keys. Dropping a key directly on another replaces that key; Undo restores it.

Keyframes animate the base settings. Music and the automatic camera can add motion on top. For an exact manual camera path, switch Automatic camera off. Raster line count and mesh detail stay unanimated. Use Save animation to keep keys, base settings and section timing. It does not store media. Save look saves only the currently evaluated pose.

Real 4K, not a bigger screen recording

Preview resolution does not set export resolution. Export renders every frame at 3840 × 2160, waits for encoding, and includes the song when selected. Slower computers can take longer than real time.

Use current desktop Chrome or Edge. MP4/H.264 availability depends on the browser and hardware. WebM/VP8 is offered when available; YouTube accepts WebM too. No unsupported export silently becomes 1080p.

Long exports write to local disk or browser-private temporary storage. Open the app in its own tab if an embedded preview blocks storage. Keep sufficient free space and the tab open. Temporary exports can be removed below.

This is an SDR browser recreation, not the Fusion macro running online. HDR colour and every Resolve-rendering detail are not reproduced. Reloading resets selected media and edits; use Save look or Save animation to keep your edits.
